# Grounds map (outdoor terrain)

The outdoor map is a 2 x 2 km Terrain3D terrain with 1 m cells. Its vertical datum is
the Black Lake surface: **y = 0 is the water line**. The lake bed goes down to
about -16 m, the castle promontory sits at 58 m and the mountain ring reaches
about 165 m. The castle interior is a separate map.

## Pipeline

The source lives in the workspace's `art/map/` folder, next to this repository:

| Path | What it is |
| --- | --- |
| `art/map/layout.json` | The design: base relief, lake, plateaus/hills/hollows, biome regions, roads, landmarks, and where gameplay content moves (`gameplay_migration`) |
| `art/map/scripts/heightfield.py` | layout -> `out/height.raw` (2048^2 float32 metres) + `stats.json` (landmark heights, road grades) |
| `art/map/scripts/control.py` | layout + heights -> `out/control.raw` (Terrain3D control words: base/overlay texture, blend) |
| `art/map/scripts/plan_render.py` | Top-down plan and oblique review renders |
| `art/map/scripts/pack_terrain_textures.py` | Packs PBR sets into Terrain3D's 1024 px albedo+height / normal+roughness pairs |

In this repository:

| Path | What it is |
| --- | --- |
| `tools/terrain/build_grounds.gd` | Imports `height.raw` + `control.raw` into Terrain3D regions and writes the texture set |
| `assets/terrain/grounds/data/*.res` | The four 1024 m regions (Git LFS) |
| `assets/terrain/grounds_assets.tres` | The 8 ground textures, generated by the build |
| `assets/terrain/grounds_material.tres` | Shader settings, **hand-authored** (a headless build has no shader to hold them) |
| `assets/terrain/textures/` | Packed ground textures (import: VRAM compressed, high quality, normal map disabled, mipmaps) |
| `scenes/world/grounds_terrain.tscn` + `scripts/world/grounds_terrain.gd` | The terrain node (`GroundsTerrain`) |
| `tools/terrain/grounds_preview.tscn` | Walk / fly preview (F6 in the editor) |
| `scripts/test/grounds_regression.gd` | Data, painting, collision and walking checks |

Rebuild after changing the layout:

```
cd art/map
python scripts/heightfield.py layout.json out
python scripts/control.py layout.json out
cd ../../client
godot --headless --path . -s tools/terrain/build_grounds.gd -- --src ../art/map/out
godot --headless --path . res://scenes/test/grounds_regression.tscn
```

## Texture slots

The slot order is a contract between `control.py`, `build_grounds.gd` and the
regression test:

| Slot | Name | Where control.py paints it |
| --- | --- | --- |
| 0 | grass_meadow | default ground |
| 1 | cliff_rock | slopes above ~30 deg, high moor |
| 2 | forest_floor | Forbidden Forest region |
| 3 | sand_shore | lake bed and beaches |
| 4 | gravel | road shoulders, wet shoreline |
| 5 | dirt_path | road centres (the sand set tinted to packed earth) |
| 6 | cobblestone | roads on the castle plateau and in Hogsmeade, the two plazas |
| 7 | grass_lush | overlay patches on the meadow |

The auto-shader is off: every texel is painted explicitly, so what the plan
shows is what the game shows. Hand touch-ups in the Terrain3D editor are fine,
but a rebuild overwrites them; move lasting changes into `control.py` rules.

## Collision

The dedicated server simulates every player's body wherever it is, so headless
runs use `FULL_GAME` collision (the whole heightfield). A client only needs the
ground near its camera and uses `DYNAMIC_GAME` with a 96 m radius. Dynamic
collision cannot work headless; that is why the mode is chosen by display server
and not by a flag. The ground collider is on physics layer 1, like every other
walkable surface.

`GroundsTerrain.height_at(x, z)` returns the ground height (NaN outside the map
or with no grounds loaded). It replaces `OutdoorTerrain.ground_y` once the
outdoor map moves over (phase 5).
